Architecture of the application: (valid for all platforms)
----------------------------------------------------------------------------------------

Application Platform Dependent code     - Creates the application in a given system / platform.
Application Platform Independet code    - The portion of the application which uses the FuetEngine to implement a 2D graphics application.
FuetEngine Platform independent code    - Provides classes and functionality to implement a 2D graphics application.
FuetEngine Platform dependent code      - Provides functionality to the engine platform independent code to implement whatever the user application may require.
